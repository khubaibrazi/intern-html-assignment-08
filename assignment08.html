Day 1–2: HTML essentials

Review the same concepts used in the personal profile and tables-and-forms practice assignments.

01. HTML document structure

An HTML page starts with a doctype and includes html, head, and body. Use headings in a sensible order and lists for grouped items. 

<!DOCTYPE html>
<html lang="en">
  <head><title>My Page</title></head>
  <body><h1>Welcome</h1></body>
</html>

02. Semantic text and content

Use header, nav, main, section, article, aside and footer to express meaning. strong indicates importance and em indicates emphasis.

Tip: Choose HTML elements for meaning; use CSS for appearance.

03. Links and accessible images

Use a for navigation and img for meaningful imagery. An image needs helpful alt text; its size is controlled responsively in CSS with max-width, aspect-ratio and object-fit. 

<a href="#courses">Explore courses</a>
<img src="photo.jpg" alt="Student writing HTML">

04. Tables and column groups

A data table uses caption, thead, tbody, tfoot, tr, th, and td. colgroup and col can define column styling. See the sample performance table below.

Open student table →

05. Better forms and fieldsets

A useful form connects each label to an input's id. Group related controls inside a fieldset with a legend. Use required, min, and max to let the browser validate entries.

Try the form below →

06. Advanced HTML form controls

Practice select and optgroup to present fixed choices, datalist to suggest values, and inputs such as date, time, month, week, color, range and file.

What's the difference between select and datalist?

A select lets users pick from available options. A datalist suggests options for an input while still allowing custom text.
